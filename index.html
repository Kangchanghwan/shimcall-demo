고양·파주 마사지샵 안내 웹 제안공고를 보고 화면을 먼저 만들어 봤습니다.

왼쪽 화면은 직접 만져볼 수 있습니다. 지도를 끌어보고, 동을 골라보고, 샵을 눌러 상세까지 들어가 보세요. 스마트폰으로 열면 실제 서비스와 같은 크기로 보이고, 홈 화면에 추가하면 앱처럼 아이콘이 생깁니다.

공고에 적어주신 필수 과업을 기준으로 만들었습니다. 지도와 목록은 같이 움직입니다. 지도를 옮기면 "이 지역에서 다시 검색"이 뜨고, 목록에서 샵을 누르면 지도가 그 샵으로 갑니다. 아래 목록은 손으로 끌어올려 절반, 전체 순으로 펼칠 수 있습니다. 동 필터는 고양시 세 개 구와 파주시로 나눠서 동을 여러 개 고를 수 있게 했습니다. 상세 화면에는 사진, 주소, 영업시간, 소개가 있고 맨 아래 전화 버튼이 고정되어 있습니다.

관리자 화면에서는 샵을 등록하고 고치고 숨길 수 있고, 사진을 올리고, 지도를 눌러 위치를 찍습니다. 동별로 노출을 끌 수도 있습니다. 여기서 고친 내용은 사용자 화면에 바로 반영됩니다. 대시보드에는 샵마다 전화 버튼이 눌린 횟수를 세어 두었는데, 나중에 샵을 모집하실 때 "지난달에 전화가 몇 건 갔다"고 보여드릴 수 있어서 넣었습니다.

스마트폰으로 열어보기카메라로 QR을 찍으면 사용자 화면이 열립니다.
Safari나 Chrome 메뉴에서 "홈 화면에 추가"를 누르면 앱 아이콘이 생깁니다.

공고의 필수 과업을 어디서 확인할 수 있는지

필수 과업데모에서 보는 방법
지도와 리스트첫 화면입니다. 마커가 몰린 곳은 숫자로 묶이고 확대하면 풀립니다. 목록은 지도에 보이는 샵을 가까운 순으로 보여줍니다.
동 단위 필터위쪽 "전체 지역" 버튼을 누르면 시 탭과 동 목록이 나옵니다. 여러 동을 고르고 적용하면 지도가 그 범위로 이동합니다.
샵 상세상호, 사진(옆으로 넘김), 주소, 전화번호, 영업시간, 소개, 위치 지도가 있습니다. 영업시간을 보고 지금 영업중인지 표시합니다.
전화하기상세 맨 아래 버튼과 목록의 전화 아이콘입니다. 스마트폰에서는 통화 앱이 바로 열립니다. 누른 횟수는 관리자 대시보드에 쌓입니다.
비회원 열람로그인 화면이 없습니다.
PWAAndroid에서는 설치 안내가 아래에 뜹니다. iPhone은 Safari 공유 버튼에서 "홈 화면에 추가"를 눌러야 해서 그 안내를 대신 띄웁니다.
관리자 웹샵 등록, 수정, 숨김, 사진 등록, 동 노출 설정, 전화 클릭 통계까지 들어 있습니다.
제휴 구분 없음모든 샵이 같은 모양으로 나옵니다. 데이터에 제휴 여부 칸만 비워 두었고 화면에는 쓰지 않습니다.

관리자 화면

PC에서 쓰는 화면입니다. 왼쪽 메뉴의 샵 관리에서 노출 스위치를 하나 꺼 보시면 위 스마트폰 화면의 목록에서 그 샵이 빠집니다.

이 데모와 실제 납품물이 다른 점

지도는 지금 OpenStreetMap을 쓰고 있습니다. 카카오맵은 개발자 키를 발급받고 도메인을 등록해야 뜨기 때문에, 미리 보여드리는 단계에서는 키 없이 열리는 지도를 썼습니다. 실제 개발에서는 카카오맵으로 바꿉니다. 지도를 다루는 코드를 파일 하나에 모아 두어서 그 파일만 바꾸면 되고 나머지 화면은 그대로입니다.

샵 41곳은 전부 제가 만든 가상의 데이터입니다. 상호, 주소, 전화번호 모두 실제 업체와 관계없고 사진도 무료 샘플 이미지입니다. 데이터는 지금 브라우저 안에만 저장되어 있어서 관리자 화면에서 고친 내용은 고친 사람의 브라우저에서만 보입니다. 실제 서비스는 서버에 데이터베이스를 두고 사진은 별도 저장소에 올립니다.

관리자 화면에 로그인이 없습니다. 실제 납품 시에는 관리자 계정과 로그인을 넣습니다. 공고에서 2차로 미뤄두신 항목(지역 켜고 끄기, 제휴 여부, 예약 요청)은 지금 데이터 구조에 칸을 비워 둔 상태라, 붙일 때 화면을 새로 짜지 않고 그 칸을 채우는 식으로 갑니다.

제안 검토용으로 만든 페이지입니다. 매장 정보는 모두 가상의 샘플이고, "쉼콜"이라는 이름은 임시로 붙인 것입니다.
