미리 만들어 봤습니다.

왼쪽 화면은 그림이 아니라 실제로 동작하는 웹입니다. 지도를 움직이고, 동을 고르고, 샵을 눌러 상세까지 들어가 보세요. 스마트폰에서 열면 실제 서비스와 같은 화면으로 보이고, 홈 화면에 추가(PWA)도 됩니다.

  • 1지도 + 리스트가 함께 동작 — 지도를 움직이면 "이 지역에서 다시 검색"으로 아래 목록이 갱신되고, 목록을 누르면 지도가 해당 샵으로 이동합니다. 아래 시트는 끌어올려 3단계(살짝/절반/전체)로 열립니다.
  • 2동 단위 필터 — 고양시(덕양·일산동·일산서구) / 파주시 안에서 동을 여러 개 골라 거릅니다.
  • 3샵 상세 → 전화하기 — 사진, 주소(복사·길찾기), 영업시간(영업중 표시), 소개, 하단 고정 전화하기 버튼.
  • 4관리자 웹 — 샵 등록·수정·숨김, 사진 업로드, 지도에서 핀 찍기, 동 노출 ON/OFF, 그리고 샵별 전화 클릭 통계. 관리자에서 고친 내용이 사용자 웹에 바로 반영됩니다.
스마트폰으로 열어보기카메라로 QR을 찍으면 사용자 웹이 열립니다.
Safari/Chrome 메뉴에서 "홈 화면에 추가"를 누르면 앱 아이콘이 생깁니다.

데모와 실제 서비스의 차이 (정직하게)

지도 엔진

데모는 키 발급 없이 바로 뜨는 오픈 지도(OpenStreetMap)를 씁니다. 실제 서비스는 카카오맵으로 교체합니다. 앱 코드는 지도 어댑터 한 파일만 바라보도록 만들어 두어, 교체 시 다른 화면은 손대지 않습니다.

데이터 저장

데모는 샘플 41곳(상호·주소·전화는 가상)을 브라우저 안에 저장합니다. 실제 서비스는 서버 DB(PostgreSQL)와 API를 두고, 사진은 오브젝트 스토리지에 올립니다. 화면 코드는 동일하게 유지됩니다.

관리자 로그인

데모는 로그인 없이 열립니다. 실제 서비스는 관리자 계정 로그인과 접근 제한이 들어갑니다. 2차 항목(지역 ON/OFF, 제휴 필드, 예약 요청)은 같은 구조에 열만 추가하는 방식으로 붙입니다.
본 페이지는 프로젝트 제안을 위한 시연용이며, 표시된 매장 정보는 모두 가상의 샘플 데이터입니다. 브랜드명 "쉼콜"은 가칭입니다.
